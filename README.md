# Medical Billing Management System

A console-based Medical Store Management System developed in
8086 Assembly Language. The system manages medicine sales,
product information, stock levels, billing, and low-stock detection
through a simple menu-driven interface.

## Features

- Product sales management
- Medicine/product selection
- Quantity-based billing
- Automatic total calculation
- Product details and pricing
- Stock quantity management
- Low-stock detection
- Receipt generation
- Menu-driven navigation
- Input validation
- Multiple product management

## Technologies Used

- 8086 Assembly Language
- MASM/TASM
- DOS Interrupts
- x86 Architecture

## How It Works
- Main Menu
When the program starts, the user is presented with options for product sales, product details, and exiting the system.

- Product Sale
The user can select a medicine/product and enter the required quantity. The system calculates the total price automatically.

- Billing
The system generates a bill based on the selected product, quantity, and price.

- Product Details
Users can view available products along with their product IDs, prices, and stock quantities.

- Low Stock Detection
The system checks product quantities and identifies products with low available stock.
